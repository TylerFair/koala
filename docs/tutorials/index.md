# Tutorials

Each tutorial shows the configuration, the command, and the result.

- [Fit your first transit](soss_order1.md): the bundled WASP-39 b
  NIRISS/SOSS transit, from configuration to transmission spectrum.
- [WASP-39 b secondary eclipse](wasp39_eclipse.md): an emission spectrum
  from NIRSpec/G395H.
- [Synthetic thermal phase curve](phase_curve.md): dayside and nightside
  flux, hotspot offset, and the planet's flux around the orbit.
- [Fit limb asymmetry with Harmonica](harmonica.md): separate spectra for
  the two terminator halves.
